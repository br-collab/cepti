# Cepti

A modern business website built with [Next.js](https://nextjs.org), TypeScript, and Tailwind CSS.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Responsive navigation header with mobile menu
- Hero section with call-to-action
- Services section showcasing offerings
- About section with company info and stats
- Testimonials from clients
- Contact form
- Footer with links and social icons

## Tech Stack

- [Next.js 16](https://nextjs.org/) – React framework
- [TypeScript](https://www.typescriptlang.org/) – Type safety
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS
